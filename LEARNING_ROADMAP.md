### Semester 1 – Foundations (Current)

**Core Skills:** Python basics, Linux terminal, Git/GitHub, computer science fundamentals and probability.

**Projects:**

- GitHub Profile README
- CineTrack – Movie Watchlist & Rating Analyzer

**Certifications:** HackerRank Python (Basic) – Completed.

**Platforms:**
- HackerRank – Python practice
- LeetCode – Two Sum and Palindrome Number
- freeCodeCamp – 25 introductory steps completed

**Weekly Habit:** 2–3 hours of self-study beyond scheduled lab hours.

### Semester 2 – Core Computer Science

**Core Skills:** Arrays, linked lists, stacks, queues, trees and Python OOP.

**Languages:** Python OOP and C++ basics.

**Projects:** DSA Implementation Repository with at least 5 data structures.

**Certification Target:** NPTEL Introduction to Programming in Python, if offered.

**Platforms:** LeetCode Easy – 50 problems target; GeeksForGeeks DSA track.

### Semester 3 – Intermediate

**Core Skills:** MySQL, SQL queries, joins, indexes, HTML, CSS and JavaScript.

**Theory:** DBMS, Computer Networks and Operating Systems.

**Projects:** Student Record Management System using Python and MySQL.

**Certification Target:** Google IT Support Certificate (Coursera).

**Platforms:** HackerRank SQL and freeCodeCamp Responsive Web Design.

### Semester 4 – Intermediate to Advanced

**Core Skills:** Flask or Django, REST APIs, database integration and algorithms.

**Theory:** Design and Analysis of Algorithms and Software Engineering.

**Projects:** Task Manager Application using Flask, SQLite, HTML and CSS.

**Certification Target:** AWS Cloud Practitioner learning path.

**Platforms:** LeetCode Medium – 30 problems target; HackerRank Problem Solving.

**Career Target:** Start applying for internships and connect with professionals.

### Semester 5 – Specialisation: Data Science & AI / ML

**Core Skills:**
- NumPy and Pandas
- Data cleaning and analysis
- Matplotlib and data visualisation
- Scikit-learn
- Machine Learning fundamentals
- Jupyter Notebook

**Projects:**
- Movie Rating Analysis and Recommendation System
- Student Performance Prediction System

**Internship Target:** Apply for a 2-month Data Science or AI/ML internship.

**Certification Target:** Relevant Machine Learning certification or course.

**Platforms:** Kaggle competitions and datasets.

### Semester 6 – Industry Ready

**Capstone:** Major AI/ML team project with a faculty or industry mentor.

**Resume:** Include at least 3 strong projects, internship experience and certifications.

**Portfolio:** Maintain 5+ quality GitHub repositories and an updated LinkedIn profile.

**DSA:** Reach 100+ LeetCode problems solved.

**Career Target:** Prepare for technical interviews and campus placements.
